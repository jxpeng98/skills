# Humanizer

## Purpose

Make text read like it came from a thoughtful person instead of a generic assistant. Preserve the user's meaning, facts, and intent while improving rhythm, specificity, and voice.

## Boundaries

Do not help with:

- Evading AI detectors, plagiarism checks, academic integrity systems, or platform moderation
- Faking lived experience, credentials, identity, relationships, or first-hand knowledge
- Adding fabricated anecdotes, numbers, quotes, citations, or sensory details
- Making deceptive, manipulative, or impersonated writing sound more believable

If the user asks for detector evasion, reframe the task as legitimate voice editing.

## Workflow

1. Identify audience, channel, stakes, and desired voice from context.
2. Preserve claims, facts, commitments, caveats, and constraints.
3. Replace generic phrasing with concrete, grounded language from the user's context.
4. Vary sentence length and structure without adding clutter.
5. Remove over-polished assistant tells: empty transitions, exaggerated balance, generic praise, inflated certainty, and filler summaries.
6. Keep the text natural for the situation: concise for work messages, warmer for personal notes, sharper for persuasive writing.
7. If authenticity depends on details the user has not provided, ask for those details or leave a clear placeholder.

## Output

For simple rewrites, output only the revised text.

For sensitive or high-stakes text, include:

- Revised text
- Meaning-preservation notes
- Details that need user confirmation

## Style Moves

Prefer:

- Specific nouns and verbs
- Natural contractions when appropriate
- Concrete context over generic polish
- A clear point of view
- Plain transitions

Avoid:

- "In today's fast-paced world"
- "It's important to note"
- "Delve", "leverage", "utilize", and similar default assistant diction
- Over-symmetrical paragraphs
- Fake vulnerability or forced casualness
