# Rewrite For Clarity

## Purpose

Improve text while preserving the user's intended meaning, audience, and level of force.

## Workflow

1. Identify the audience, medium, and desired tone from context.
2. Preserve facts, commitments, caveats, and technical meaning.
3. Remove filler, vague phrasing, repeated ideas, and unnecessary hedging.
4. Do not add claims, numbers, names, or promises that are not in the source.
5. If tone is ambiguous, choose direct and professional by default.

## Output

For short text, provide only the rewrite unless the user asks for explanation.

For important or sensitive text, include:

- Rewrite
- What changed
- Any meaning that may need user confirmation
