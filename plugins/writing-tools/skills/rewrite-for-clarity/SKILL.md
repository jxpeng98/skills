# Rewrite For Clarity

1. Infer audience, medium, tone, and length; ask only if ambiguity changes the
   meaning or stakes.
2. Protect facts, commitments, caveats, quotations, citations, technical meaning,
   and certainty.
3. Put the point, request, decision, or conclusion where the reader needs it.
4. Remove filler, repetition, vague phrasing, unnecessary hedging, and process
   language.
5. Adapt wording and formality without adding claims, names, numbers, promises,
   examples, policy, warmth, firmness, or confidence not present in the source.

For short text, return only the rewrite. For sensitive text, add only material
changes or meaning that needs confirmation.
