# Assignment Brief

Use the syllabus, learning outcomes, existing brief, rubric, and policy text when
available. Treat explicit institutional and course policy as authoritative. Surface
source conflicts, and mark unknown policy `[Instructor to confirm]`.

1. State the learning purpose and connect each deliverable to a supplied outcome.
2. Define the task and deliverables: format, length, evidence, files, deadline,
   collaboration, and submission route.
3. Separate requirements from advice; make constraints explicit.
4. Build distinct rubric criteria from observable evidence. Align them with the
   outcomes and deliverables, using only supplied levels and weightings.
5. State allowed help, citation, collaboration, and authorship boundaries.
6. Add a short submission checklist.

Return the goal, task, deliverables, requirements, rubric, and checklist, adapted
to any supplied institutional template. Before returning it, verify that a student
can tell what to produce, why, how it is judged, and what still needs confirmation.

Do not invent dates, weights, penalties, AI-use rules, or course policy.
