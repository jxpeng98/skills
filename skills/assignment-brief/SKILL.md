# Assignment Brief

Write as an instructor would explain the task to students, in the language and
regional variety used in the course. Prefer common words and direct instructions.
Keep exact policy wording only where changing it could change the rule.

Use the syllabus, learning outcomes, existing brief, rubric, and policy text when
available. Treat explicit institutional and course policy as authoritative. Surface
source conflicts, and mark unknown policy `[Instructor to confirm]`.

1. State the learning purpose and connect each deliverable to a supplied outcome.
2. Define the task and deliverables: format, length, evidence, files, deadline,
   collaboration, and submission route.
3. Separate requirements from advice; make constraints explicit.
4. Build observable rubric criteria aligned with outcomes and deliverables.
   Preserve approved levels and weightings. When asked to design a new rubric,
   propose missing levels or weights as recommendations for instructor approval,
   not established policy; check that proposed weights sum to the stated total.
5. State allowed help, citation, collaboration, and authorship boundaries.
6. Add a short submission checklist.

For a full brief, return the goal, task, deliverables, requirements, rubric, and
checklist in the supplied template. For a focused revision or rubric request,
return that part. Before returning it, verify that a student
can tell what to produce, why, how it is judged, and what still needs confirmation.

Do not invent confirmed dates, weightings, penalties, AI-use rules, or course policy.
