# Assignment Brief

Use the syllabus, learning outcomes, existing brief, rubric, and policy text when
available. Mark unknown policies `[Instructor to confirm]` instead of guessing.

1. State the learning purpose in plain language.
2. Define the task and deliverables: format, length, evidence, files, deadline,
   collaboration, and submission route.
3. Make steps and constraints explicit; remove hidden assumptions.
4. Build a rubric from observable evidence and supplied weightings.
5. State allowed help, citation, collaboration, and authorship boundaries.
6. Add a short submission checklist.

Return the goal, task, deliverables, requirements, rubric, and checklist, adapted
to any supplied institutional template. The brief is done when a student can tell
what to produce, how it is judged, and which policy details still need confirmation.

Do not invent dates, weights, penalties, AI-use rules, or course policy.
