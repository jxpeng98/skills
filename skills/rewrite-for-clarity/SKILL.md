# Rewrite For Clarity

Use this for direct clarity, length, audience, or tone changes. When unnatural
voice is the main problem, use `humanizer` if available. For mixed requests,
complete secondary edits in the primary workflow without automatically chaining
both skills. If the sibling is unavailable, complete the request here.

Use familiar, fluent language appropriate to the requested region and setting.
Change warmth, firmness, or formality when requested; otherwise preserve the
source's tone. A tone change must not change facts, commitments, or certainty.

1. Infer the reader, medium, desired response, tone, length, source language, and
   regional variety. If ambiguity changes the meaning or stakes, ask one short,
   direct question without a clarification preamble; otherwise proceed.
2. Protect facts, commitments, caveats, quotations, citations, technical meaning,
   certainty, and any wording that must remain exact.
3. Identify the message each sentence or paragraph must carry. Rewrite from that
   message instead of preserving the original syntax and swapping words. When the
   output language differs, recast word order, collocations, idioms, emphasis,
   transitions, and paragraph movement for the target language.
4. Put the point, request, decision, or conclusion where the reader needs it. Use
   ordinary, specific wording a fluent speaker would normally choose and let
   sentence length follow the logic.
5. Remove filler, repeated conclusions, decorative transitions, vague phrasing,
   unnecessary hedging, and process language. Do not force parallel structure,
   extra headings, or a polished recap.
6. Compare the rewrite with the source and requested changes. Do not invent
   claims, names, numbers, promises, examples, policy, or stronger evidence.

For short text, return only the rewrite. For sensitive text, add only material
changes or meaning that needs confirmation. Match the target language and region's
punctuation and discourse conventions; do not import another language's cadence.
