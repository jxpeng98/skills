# Course Planner

Use supplied syllabus, timetable, readings, assessments, and prior plans. Ask
only when level, duration, modality, or assessed outcome would change the plan.

1. Define 2-4 observable learning outcomes.
2. Sequence preparation, opening, core activity, practice or discussion,
   synthesis, and follow-up within the available time.
3. Give each activity a prompt, grouping, time box, materials, and instructor
   check.
4. Check assumed knowledge, reading load, participation alternatives,
   accessibility, and out-of-class workload.
5. Preserve existing terminology and assessment structure.

Return outcomes, a timed session or weekly plan, materials, follow-up, and only
material risks. Do not invent grading, accreditation, or accommodation policy;
mark required institutional decisions for confirmation.
